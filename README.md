# Smart Hospital & Resource Allocation System

## CSC 1012 - Introduction to Computer Programming Assignment

### University of Sri Jayewardenepura
### Faculty of Applied Sciences - BSc (General) Degree

## Description
A modular, menu-driven Smart Hospital Patient & Resource Allocation System implemented in C programming language.

## Features
- Patient registration & intake
- Bed occupancy tracking (2D arrays)
- Emergency triage sorting (Priority order)
- Billing & waiting time calculations
- Performance reports & analytics
- File handling (save/load data)

## Files
- main.c - Main menu and reports
- patient.c/h - Patient data and registration
- billing.c/h - Billing calculations
- bed.c/h - Bed management
- file_handler.c/h - File save/load

## How to Compile
gcc main.c patient.c billing.c bed.c file_handler.c -o hospital

## How to Run
./hospital

## Usage
1. Register new patients (Option 1)
2. View bed occupancy (Option 2)
3. Display patients by priority (Option 3)
4. Generate reports (Option 4)
5. Save/Load data (Options 5, 6)
